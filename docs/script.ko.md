# 진행 대본: DevOps 체험하기: 카오스 엔지니어링(AWS FIS)과 온콜 대응(CloudWatch, SNS, OpsCenter)

진행자가 55분 동안 말하고 누르는 순서를 그대로 적은 대본이다. 각 장면의 **화면**은 `docs/walkthrough.ko.md`의 스크린샷 번호다. **말**은 그대로 읽어도 되는 문장이고, **손**은 진행자가 누르거나 치는 것, **참가자**는 그 사이 참가자가 하는 일이다. 시각은 세션 시작 기준 누적 시간이다. 30분 단축 경로는 끝에 따로 있다.

시간을 적는 칸을 칠판이나 공유 문서에 미리 만들어 둔다. 적을 시각은 네 개다. 실험 시작, 첫 알람 메일, 알람 OK, 롤백 완료.

---

## 수업 전 (진행자, 당일 아침)

**화면** 01~14 (IAM), 65~66 (User Notifications)

- 참가자 계정이 관리자가 아니면 `iam/lab-policy.json`으로 정책 `devops-handson`을 만들어 각 사용자에 붙인다. 순서는 walkthrough 0절 그대로다. 정책 설명란에 콜론(`:`)을 쓰면 거부되니 넣지 않는다.
- 진행자 계정에는 스택을 미리 올려 둔다. 네트워크가 느려도 보여 줄 화면이 생긴다.
- 푸시 알림을 시연하려면 진행자 폰에 Console Mobile App을 설치하고 로그인한 뒤 User Notifications 구성을 만들어 둔다(화면 65, 66). 참가자에게는 선택 과제로만 안내한다.
- 참가자 전원이 받을 이메일 주소를 하나씩 준비했는지 확인한다. 구독 확인 메일을 못 누르면 이후 알람이 하나도 오지 않는다.

"적어 둘 숫자는 세 개입니다. 정상 오류율 0, 정상 p95 몇 밀리초, 정상 데드레터 깊이 0."
